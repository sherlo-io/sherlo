1. Let Sherlo open Storybook
   Storybook starts from your app's code, so Sherlo can't open it alone. Pick one:

   a) Entry-point swapping (Storybook's default, recommended)
      In .rnstorybook/index.ts, below StorybookUIRoot, add:
        import { registerRootComponent } from 'expo';
        import { isStorybookMode } from '@sherlo/react-native-storybook';
        // Storybook in Storybook mode; the app otherwise, as a scene launch needs it.
        if (isStorybookMode) {
          registerRootComponent(StorybookUIRoot);
        } else {
          require('../index');
        }
      Then remove your app's code that renders Storybook, and its import.

   b) In-app integration
      At the top of App.tsx, add:
        import { isStorybookMode } from '@sherlo/react-native-storybook';
        import Storybook from './.rnstorybook';
      Remove these lines from App.tsx:
        let AppEntryPoint = App;
        if (process.env.EXPO_PUBLIC_STORYBOOK_ENABLED === 'true') {
          AppEntryPoint = require('./.rnstorybook').default;
        }
      Replace export default AppEntryPoint; with:
        export default function AppOrStorybook(props: any) {
          if (isStorybookMode) return <Storybook />;
          return <App {...props} />;
        }
