1. Let Sherlo open Storybook
   Storybook is installed, but your app doesn't start it yet, so Sherlo can't open it. Pick one:

   a) Entry-point swapping (Storybook's default, recommended)
      In .rnstorybook/index.ts, below StorybookUIRoot, add:
        import { AppRegistry } from 'react-native';
        import { name as appName } from '../app.json';
        AppRegistry.registerComponent(appName, () => StorybookUIRoot);

   b) In-app integration
      At the top of App.tsx, add:
        import { isStorybookMode } from '@sherlo/react-native-storybook';
        import Storybook from './.rnstorybook';
      Change export default function App() { to:
        function App() {
      At the end of App.tsx, add:
        export default function AppOrStorybook() {
          if (isStorybookMode) return <Storybook />;
          return <App />;
        }

2. Replace the example stories

     export const Default = { args: { title: 'Default' } };
