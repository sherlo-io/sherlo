1. Add .rnstorybook/main.ts
   .rnstorybook has no main file, which lists your stories. Add .rnstorybook/main.ts:
     import type { StorybookConfig } from '@storybook/react-native';

     const main: StorybookConfig = {
       stories: ['../*.stories.?(ts|tsx|js|jsx)'],
     };

     export default main;

2. Write your first stories
   Your app has no stories yet. Write them in your app's folder itself, where main.ts looks.

   You can start with a few components or screens, one story per state:
     // Button.stories.tsx
     import { Button } from './Button';
     export default { component: Button };
     export const Default = { args: { title: 'Default' } };
     export const Disabled = { args: { title: 'Disabled', disabled: true } };

   Before you write stories, read:
     node_modules/@sherlo/react-native-storybook/guides/writing-stories.md

   npx sherlo test
